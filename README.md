# BugHunter Pro — AI Code Verification Master

**BugHunter Pro** is an AI code checker & bug finder. Paste AI-generated code and verify it through 12 layers before it reaches production.

> AI writes fast. You verify like a master.

## Features

- **Verifier Lab** — paste code in Python, JavaScript, TypeScript, HTML & Java
- **12-layer live scan** with animated progress and real bug detection
- **120 bug classes** — searchable taxonomy with severity, line number & fix
- **100-point score** — animated score ring, PASS / REJECT verdict (1 CRITICAL = auto REJECT)
- **1-tap fixes** — Apply Fix for auto-fixable bugs, Copy Fix for the rest
- **Bug Samjhao Mode (FREE)** — every bug explained in simple English + easy Urdu
- **Daily Bug Challenge (FREE)** — a new challenge every day, +10 points, streak counter
- **Dark / Light Mode (FREE)** — smooth theme switch, saved
- **Scan History** — every scan saved, tap to reload its report
- **Master Prompt** — copy-paste prompt to force any AI to verify code properly
- **5 free scans per day**

Open `index.html` in a browser — no build step, no server needed. Works on phone & laptop.
